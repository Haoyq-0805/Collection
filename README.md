## 精选项目

### 01｜在“推动”与“管控”之间

**十年中美通稿里的外交语言之变**

从中方涉美通稿中的态度动词出发，以词频和年度占比观察合作推进与风险管理的表达变化，并结合图表讨论沟通、边界与共识落实。统计涵盖 2017 年至统计时点已收录的 2026 年通稿，年度阶段比较使用 2017—2025 年完整数据。

**项目形式：** 小组作品 · 数据分析与议题写作  
[查看完整作品 →](works/外交话语分析.pdf)

### 02｜网络热词生命周期与传播机制研究

以“汉语盘点”中的 73 个网络热词及百度指数日度数据为基础，从生命周期、热度量级、传播形态与半衰期等维度构建指标，运用系统聚类和 K-means 聚类归纳传播类型。报告将样本划分为平稳发酵型、长期流行型和短期爆火型。

**个人分工：** 聚类分析、研究方法与数据分析部分撰写。  
**项目形式：** 小组课程研究 · 传播数据分析  
[查看完整报告 →](works/网络热词研究.pdf)

### 03｜“橙心优果”助农品牌策划案

围绕地方柑橘产业与助农场景，梳理品牌现状、市场定位和竞争环境，提出品牌建设、礼盒包装与分阶段活动方案，并讨论预算和运营风险。

**项目形式：** 品牌策划方案  
[查看完整策划案 →](works/橙心优果品牌策划.pdf)

### 04｜超能植愈香氛品牌传播策划

围绕香氛洗护产品的品牌认知与年轻化传播，结合市场、竞品和消费者分析，提出“天然植愈之旅——穿在身上的莫奈香氛”创意主题，以及线上内容、线下体验和分阶段传播计划。

**项目形式：** 广告与整合传播策划方案  
[下载完整策划案 →](works/超能品牌传播策划.docx)

### 05｜御空智训

**面向低空运动场景的多模态智能体感知与训练评估系统**

针对运动影像采集与训练复盘需求，项目将无人机采集控制端 UAVFace 与训练复盘端 Coach 相结合：前者通过身份确认与视觉跟随记录指定运动者，后者利用姿态关键点对徒手动作进行分段、计次和指标分析，并在证据充分时给出评分。可选 AI Agent 基于结构化结果辅助解释与训练计划生成。

**项目形式：** 全国大学生物联网设计竞赛作品 · 团队项目；**个人角色：** 队长。

**技术关键词：** DJI Tello TT、InsightFace、YOLO、MediaPipe Pose、AI Agent。

**验证情况：** 文档记录了原型飞行、录像与本地分析链路的有限验证，并列出了降落失败、采集中断等有待改进的问题。

[下载完整文档 →](works/御空智训——面向低空运动场景的多模态智能体感知与训练评估系统.docx)
